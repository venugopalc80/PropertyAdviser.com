# PropertyAdviser.com

USA-focused property search and real estate discovery demo.

## Scope
- Property search across the United States
- Buy and rent discovery flows
- Property cards with price, beds, baths, sqft and location
- Search filters for location, price, property type, bedrooms and bathrooms
- Featured listings and market-focused content
- Responsive desktop/mobile layout

## Design direction
A clean, premium US real-estate portal inspired by modern property marketplaces, with original branding and UI.

## Planned stack
React + Vite, responsive CSS, reusable UI components and mock listing data for the demo.
